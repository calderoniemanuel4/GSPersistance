# Conversor de Pies y Metros

Aplicacion sencilla en Streamlit para convertir valores entre pies y metros.

## Requisitos

- Python 3
- Streamlit

## Instalacion

```bash
pip install -r requirements.txt
```

## Ejecucion

```bash
streamlit run streamlit_app.py
```

Tambien puedes ejecutar:

```bash
python3 -m streamlit run streamlit_app.py
```

## Uso

1. Selecciona la unidad de origen con el switch.
2. Ingresa un numero valido.
3. Pulsa `Convertir` para ver el resultado.
4. Pulsa `Salir` para detener la interfaz en la pagina.

## Archivos

- `streamlit_app.py`: aplicacion principal.
- `requirements.txt`: dependencias necesarias.
