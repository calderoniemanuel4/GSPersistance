Buenas Prácticas de Python Coding

Guía didáctica para escribir código Python limpio, mantenible y profesional.

Listo para exportar.

1. Escribe código legible

  • Usa nombres claros: total_price es mejor que tp.
  • Evita funciones largas con muchas responsabilidades.
  • Prioriza claridad sobre trucos de una sola línea.

2. Respeta PEP 8

  • Indentación de 4 espacios y estilo consistente.
  • Espacios correctos alrededor de operadores.
  • Organiza imports en bloques lógicos.
def calculate_total(items: list[float]) -> float:
    return sum(items)

3. Usa type hints y docstrings

  • Agrega tipos para facilitar mantenimiento y validación.
  • Documenta funciones públicas con propósito, args y retorno.
def load_users(path: str) -> list[dict]:
    """Load users from a JSON file."""
    ...

4. Maneja errores de forma explícita

  • Captura excepciones específicas.
  • No silencies errores críticos.
  • Propaga contexto útil para debugging.
try:
    data = json.loads(payload)
except json.JSONDecodeError as exc:
    raise ValueError("Payload inválido") from exc

5. Separa capas del proyecto

  • Modelo de datos separado de servicios.
  • Lógica de negocio separada de UI/API.
  • Configuración centralizada en un módulo.

6. Testea lo crítico

  • Usa pytest para pruebas automatizadas.
  • Cubre parsing, validaciones y reglas de negocio.
  • Mantén tests rápidos y reproducibles.

7. Seguridad y configuración

  • No hardcodees claves o tokens.
  • Usa variables de entorno y .env.example.
  • Protege secretos con .gitignore.
